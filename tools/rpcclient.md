# RPCclient


## Boş User İle bağlanma

```bash
rpcclient -U "" 10.129.14.128
```

| Sorgu | Açıklama |
|---|---|
| `srvinfo` | Sunucu bilgisini gösterir. |
| `enumdomains` | Ağda yapılandırılmış tüm alan adlarını (domain) listeler. |
| `querydominfo` | Dağıtılmış alan adları hakkında alan adı, sunucu ve kullanıcı bilgilerini gösterir. |
| `netshareenumall` | Erişilebilir tüm paylaşımları listeler. |
| `netsharegetinfo <share>` | Belirtilen paylaşım hakkında bilgi verir. |
| `enumdomusers` | Alan adındaki tüm kullanıcıları listeler. |
| `queryuser <RID>` | Belirtilen RID'e sahip kullanıcı hakkında bilgi verir. |

Bu sorgular `rpcclient` aracının içinde çalışır. Bağlanmak için örnek kullanım:
